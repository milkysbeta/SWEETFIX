# Sample photography

Stand-ins so the design can be judged against real photography.
**None of these are Matt's work.** Every one is badged "Sample" on the
site, and the badge disappears the moment a real photo is listed in a
project's `images` array in `src/lib/site.ts`.

Source: Unsplash, under the Unsplash Licence — free for commercial use,
no attribution required. Credited anyway, because the photographers
deserve it and because it records exactly what has to be replaced.

## Replacing them

Drop real photos into `public/images/work/<project-id>/`, list them in
the project's `images` array, and delete the `samples` line. Nothing
else to change.
